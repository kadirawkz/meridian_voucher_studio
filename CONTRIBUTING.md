# Contributing

Thank you for considering contributing to Meridian Voucher Studio.

- Fork the repository and create feature branches from `main`.
- Run `npm install` and ensure typechecking passes: `npm run typecheck`.
- Run linting and formatting: `npm run lint`.
- Keep changes focused; avoid committing large binaries.
- Before opening a PR, ensure no secrets are present in your commits.

If you're preparing changes for public release, follow the `README.md` checklist.
